# Конвертер изображений

Пункты «Конвертировать в», «Повернуть» и «Отразить» в контекстном меню Проводника.

```
Конвертировать в  ▶   PNG · JPEG · WebP · AVIF · HEIC
                      GIF · BMP · TIFF · ICO · PDF
                      ───────────────
                      Ещё форматы ▶  JPEG 2000 · TGA · PCX · DDS
                                     ICNS · QOI · PPM · SGI · EPS · XBM
Повернуть         ▶   Вправо 90° · Влево 90° · На 180°
Отразить          ▶   По горизонтали · По вертикали
```

Работает и на нескольких выделенных файлах сразу. Пункты появляются на 38
расширениях — от привычных `.png` и `.jpg` до `.avif`, `.heic`, `.psd` и `.qoi`.

## На Windows 11 пункт спрятан

Записи из реестра Windows 11 показывает только под **«Показать дополнительные
параметры»** — или сразу по **Shift + правый клик**. Это не недоделка: попасть в
новое меню верхнего уровня можно лишь подписанным MSIX-пакетом с COM-обработчиком,
а установка сертификата требует прав администратора, чего EwScripts себе не
позволяет. На Windows 10 пункт виден сразу.

## Что происходит с файлами

Конвертация кладёт результат **рядом с оригиналом**: `photo.jpg` → `photo.png`.
Если такой файл уже есть, получится `photo (2).png` — существующее не
перезаписывается никогда. Оригинал остаётся на месте.

Поворот и отражение работают **на месте**, как это делает сам Windows. PNG и
прочие форматы без потерь; JPEG пересжимается с качеством 95 — глазом незаметно,
но при десятках поворотов одного файла качество будет понемногу падать.

Три вещи, на которых такие конвертеры обычно спотыкаются, и что здесь с ними:

| | |
| --- | --- |
| прозрачность | У JPEG, PDF, BMP, PCX, PPM, SGI, EPS нет альфа-канала. Прозрачное кладётся на подложку, по умолчанию белую. |
| анимация | Многокадровые GIF и WebP переносятся целиком в GIF, WebP, APNG и TIFF. В остальные форматы уходит первый кадр. |
| EXIF-ориентация | Применяется к пикселям, а метка снимается — иначе просмотрщик развернул бы фото повторно. |

Один повреждённый файл не останавливает остальные: что не получилось,
перечисляется в одном окне после обработки. При успехе окон не показывается.

## Настройки

`%LOCALAPPDATA%\EwScripts\data\imgconv\settings.json`, создаётся при установке:

```json
{
  "quality": { "JPEG": 95, "WEBP": 90, "AVIF": 80, "HEIF": 90, "JPEG2000": 80 },
  "background": "#FFFFFF",
  "keep_exif": true,
  "png_compress_level": 6
}
```

`background` — чем подменяется прозрачность там, где её некуда деть. Повреждённый
файл настроек не ломает конвертацию: молча берутся умолчания.

## Как устроено

```
run.py              разбор командной строки, обработка пакета файлов
imgconv/
  formats.py        какие форматы в меню и на каких расширениях
  convert.py        конвертация и повороты
  registry.py       пункты меню в HKCU, иконка
  settings.py       settings.json
  ui.py             окна с ошибками
```

Реестр пишется в `HKCU` — права администратора не нужны. Дерево пунктов
создаётся один раз в `HKCU\Software\Classes\EwScripts.ImgConv`, а расширения
ссылаются на него через `ExtendedSubCommandsKey`: иначе двадцать пунктов пришлось
бы продублировать под каждым из тридцати восьми расширений.

Из меню запускается `pythonw.exe`, чтобы не мигало окно консоли.

Удаление модуля через меню EwScripts снимает все пункты и не оставляет следов в
реестре — включая пустые ключи, если в них не оказалось чужих записей.

## Ограничения

* Только изображения. Видео и аудио потребовали бы ffmpeg — это отдельный модуль.
* Pillow пишет 31 формат, в меню взято 20. BUFR, GRIB, HDF5, SPIDER, PALM, MSP,
  IM, BLP, WMF и MPO отброшены как научные и служебные.
* PDF и EPS создаются, но обратно не читаются — Pillow умеет их только писать.
