# NetPulse

Монитор и логгер входящего/исходящего трафика Wi-Fi адаптера для Windows.
Живой дашборд в браузере, запись всех измерений в CSV, никаких внешних зависимостей.

![режим работы](https://img.shields.io/badge/Windows-10%2F11-0078d4) ![python](https://img.shields.io/badge/Python-3.10%2B-3776ab)

## Что умеет

* **Реальное время.** Скорость приёма и передачи с интервалом от 0,5 до 10 секунд.
* **Зеркальный график.** Приём вверх, передача вниз, автомасштаб оси, окна 1 / 5 / 15 / 60 минут,
  подсказка с точным значением при наведении.
* **Данные Wi-Fi.** SSID, качество сигнала и RSSI в dBm, канал, диапазон, стандарт (802.11n/ac/ax),
  тип защиты и шифрования, BSSID точки доступа, скорость линка.
* **Кто ходит в сеть.** Активные TCP-соединения, сгруппированные по процессам, с обратным DNS.
* **Логирование в CSV.** Строка на каждое измерение, отдельный файл на сутки плюс итог каждой сессии.
* **Консольный режим** — если браузер не нужен.
* **Светлая и тёмная тема**, переключение байт/биты, пауза, сброс статистики.

## Запуск

Нужен только Python 3.10+ — ни pip, ни прав администратора.

```
start.bat
```

или

```
python run.py
```

Дашборд откроется на <http://127.0.0.1:8777/>.

## Ключи командной строки

| Ключ | Что делает |
| --- | --- |
| `--list` | показать список адаптеров и выйти |
| `--iface ИМЯ` | выбрать адаптер по имени, части описания или LUID |
| `--interval СЕК`, `-n` | интервал опроса, по умолчанию `1.0` |
| `--duration СЕК`, `-d` | остановиться через N секунд (по умолчанию — до Ctrl+C) |
| `--console`, `-c` | живая сводка в терминале вместо дашборда |
| `--port ПОРТ` | порт дашборда, по умолчанию `8777` (если занят — берётся следующий) |
| `--host АДРЕС` | адрес прослушивания, по умолчанию только `127.0.0.1` |
| `--all` | показывать и виртуальные адаптеры: VPN, туннели, Wi-Fi Direct |
| `--log-dir ПУТЬ` | куда писать CSV, по умолчанию `./logs` |
| `--no-log` | не вести CSV |
| `--no-open` | не открывать браузер автоматически |
| `--no-dns` | не резолвить имена хостов в панели соединений |
| `--history N` | сколько точек держать в памяти, по умолчанию 3600 |

Примеры:

```
python run.py --interval 0.5              # опрос дважды в секунду
python run.py --console --duration 600    # 10 минут писать лог, показывая сводку в консоли
python run.py --iface Ethernet --all      # мониторить конкретный адаптер
python run.py --host 0.0.0.0              # открыть дашборд для других устройств в сети
```

## Формат логов

`logs/traffic-ГГГГ-ММ-ДД.csv` — по строке на измерение, разделитель `;`, кодировка UTF-8 с BOM
(Excel открывает без плясок с бубном):

| поле | смысл |
| --- | --- |
| `timestamp`, `epoch` | локальное время и unix-время конца интервала |
| `interval_s` | фактическая длительность интервала |
| `rx_bytes`, `tx_bytes` | принято и отправлено **за интервал** |
| `rx_bytes_per_s`, `tx_bytes_per_s` | средняя скорость на интервале |
| `rx_packets`, `tx_packets` | пакетов за интервал |
| `session_rx_bytes`, `session_tx_bytes` | накопительно с начала запуска |
| `ssid`, `signal_pct`, `rssi_dbm`, `channel` | состояние Wi-Fi на момент замера |
| `link_rx_mbps`, `link_tx_mbps` | скорость линка с точкой доступа |

`logs/sessions.csv` — по строке на каждый запуск: время, длительность, объёмы, пики.

## Как это устроено

Данные берутся напрямую из Windows API через `ctypes` — поэтому нет ни зависимостей,
ни необходимости в правах администратора, ни разбора локализованного вывода `netsh`:

| источник | что даёт |
| --- | --- |
| `iphlpapi.GetIfTable2` | счётчики байт, пакетов, ошибок по каждому интерфейсу |
| `wlanapi.WlanQueryInterface` | SSID, качество сигнала, RSSI, канал, скорость линка, защита |
| `iphlpapi.GetExtendedTcpTable` | активные TCP-соединения с PID процесса-владельца |
| `iphlpapi.GetIpAddrTable` | IPv4-адреса интерфейсов |

Скорость считается как разница накопительных счётчиков, поделённая на **фактическое**
время между опросами (`perf_counter`), а не на номинальный интервал — поэтому подтормаживание
системы не искажает цифры. Уход счётчика назад трактуется как перезапуск адаптера.

```
run.py                CLI, сборка всех частей, корректное завершение
netpulse/
  winapi.py           ctypes-обвязка над Windows API
  adapters.py         поиск адаптеров, отсев фильтр-драйверов
  sampler.py          цикл опроса, расчёт скоростей, история, подписчики
  recorder.py         запись CSV с посуточной ротацией
  connections.py      соединения по процессам + фоновый обратный DNS
  server.py           HTTP-сервер и SSE-поток измерений
  console.py          консольный режим
  web/                дашборд: index.html, style.css, app.js
```

Дашборд получает измерения по Server-Sent Events, график рисуется на `canvas`
без единой сторонней библиотеки.

## Ограничения

* Только Windows: используются системные библиотеки `iphlpapi.dll` и `wlanapi.dll`.
* Трафик считается **по адаптеру целиком**. Windows не отдаёт объём трафика по процессам
  без ETW и прав администратора, поэтому панель соединений показывает именно соединения
  и их количество, а не байты по каждому приложению.
* Счётчики адаптера включают весь трафик, в том числе служебный и широковещательный.
* Имена процессов, запущенных от другого пользователя или с повышенными правами,
  без прав администратора не читаются — вместо имени показывается `PID N`.
* Дашборд по умолчанию слушает только `127.0.0.1`. Ключ `--host 0.0.0.0` открывает его
  всей локальной сети без какой-либо аутентификации — используйте осознанно.
