EwScripts

Личные скрипты, которые ставятся одной командой. Windows 10 и 11.

Установка

[Net.ServicePointManager]::SecurityProtocol=3072; irm https://ewtizz.github.io/EwScripts/get.ps1 | iex

Начало команды включает TLS 1.2. Без него PowerShell 5.1 на многих машинах здоровается по TLS 1.0, GitHub такое соединение обрывает, и установка падает с сообщением «Базовое соединение закрыто».

Если GitHub недоступен

В некоторых сетях github.io не открывается — соединение обрывается прямо на рукопожатии. Тогда ставьте с зеркала jsDelivr, оно отдаёт копии публичных репозиториев GitHub. Дальше установщик справится сам: если архив не скачается с GitHub, он заберёт файлы через то же зеркало. 

[Net.ServicePointManager]::SecurityProtocol=3072; irm https://cdn.jsdelivr.net/gh/Ewtizz/EwScripts@main/docs/get.ps1 | iex

Что происходит

  • Откроется меню со списком модулей.
  • Всё ставится в %LOCALAPPDATA%\EwScripts — права администратора не нужны.
  • Python приносится свой, системный не трогается.
  • Пункт «Удалить EwScripts полностью» убирает всё за собой.

Модули

  • NetPulse — монитор трафика Wi-Fi с веб-дашбордом, логами в CSV и разбором по процессам.
Команда выше скачивает и выполняет код. Прежде чем запускать — его можно прочитать: get.ps1, весь репозиторий.
